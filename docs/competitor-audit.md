## Comparable live search checks

See `reports/live-*.json`, generated by `scripts/compare_search_engines.py`.
This is a **three-query smoke**, without expert relevance labels. One pass
per engine with shared provider set OpenAlex / Crossref / Europe PMC, at
five hits per provider (up to 15 merged). It records the observed DOIs,
timeouts/errors and wall-clock duration. Cold/warm caches, shared public
quota, provider response order, and asynchronous failures can differ.
The Athenaeum implementation may silently suppress per-provider errors.

**No search precision, recall, scientific claim accuracy or supremacy**
is estimated by this exercise. Comparators are installed separately
to prevent cross-project dependency contamination.

## Scientific standards

RoB 2: https://methods.cochrane.org/bias/resources/rob-2-revised-cochrane-risk-bias-tool-randomized-trials

certified RoB 2 or PRISMA 2020 complete review.
